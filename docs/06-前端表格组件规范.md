# 06 · 前端通用表格组件 DataTable 规范（分页/筛选/聚合）

> 版本：v1.0 ｜ 日期：2026-08-17
> 关联：issue #2（服务台账）、docs/05（端口约定）、web/src/table.ts
> 核心思想：**所有表格型视图统一复用一套「配置驱动」的表格组件**——
> 分页、列头筛选、分组聚合一次实现，视图只声明列定义，杜绝各视图手写重复逻辑。

## 1. 组件定位与职责

`web/src/table.ts` 提供三个能力，由**配置声明**驱动，视图零逻辑：

| 能力 | 说明 | 触发 |
|---|---|---|
| **分页** | 每页 10/20/50 可切换，页码导航，边界钳制 | 数据 > pageSize 自动出现 |
| **列头筛选** | filterable 列生成下拉（值自动去重），多列组合 AND | 声明 `filterable: true` |
| **分组聚合** | 按某列统计计数标签，点击标签过滤该组 | 声明 `groupBy: "列key"` |

状态按视图隔离（WeakMap），轮询重渲染不丢失筛选/页码。

## 2. 快速接入（三步）

```ts
// ① 声明列定义（放在模块顶层，避免每次渲染重建）
const def: TableDef = {
  cols: [
    { key: "device_name", label: "设备", filterable: true },          // 参与筛选
    { key: "status", label: "状态", filterable: true, fmt: statusCell,
      filterMap: { "0": "未解决", "1": "已解决" } },                  // 筛选值→显示名
    { key: "port", label: "端口", fmt: (r) => '<span class="num">' + r.port + "</span>" },
    { key: "url", label: "直达", fmt: linkCell },                      // 任意 HTML
  ],
  groupBy: "device_name",   // 聚合维度（可选）
  emptyMsg: "暂无数据",
};

// ② 渲染：win 内调用 table()（viewId 必须是稳定唯一字符串）
win("标题", "meta", table(def, rows, "services"))

// ③ main.ts 已全局接入 bindTableForView（render 后自动挂事件），视图无需自己绑定
```

已接入视图：`services` / `alerts` / `devices`（TABLE_ID 常量与视图一一对应）。

## 3. 列定义字段

| 字段 | 必填 | 说明 |
|---|---|---|
| `key` | ✅ | 数据行字段名（筛选/聚合/默认显示都靠它） |
| `label` | ✅ | 表头文字 |
| `fmt(row)` | 可选 | 单元格 HTML；不填默认 `String(row[key])` |
| `filterable` | 可选 | true → 该列生成筛选下拉 |
| `filterMap` | 可选 | `{原始值: 显示名}`，如 `{0:"未解决"}`；不填显示原始值 |
| `sec` | 可选 | true → 次要列：移动端（≤640px，issue #3）隐藏，关键列优先；
  th/td 自动加 `col-sec` class（CSS 媒体查询控制），桌面无影响。已标注：
  services 协议+延迟 / devices OS+8899 / alerts 来源 |

## 4. 规则与约定（新增视图必须遵守）

1. **表格型视图一律走 DataTable**，禁止手写 `tb()` + 隐藏行式过滤（旧 alerts 的做法，无分页）。
2. **TableDef 放模块顶层常量**（不要在 render 函数内重建，避免每次轮询重渲染产生新函数）。
3. **viewId 用视图名常量**（`const TABLE_ID = "services"`），全局唯一；状态按它隔离。
4. 非表格结构（隧道卡片、总览 KPI、设置表单、链路趋势图）**不套用** DataTable。
5. 交互列（如设备页 `[ping]` 按钮）用 `fmt` 渲染 HTML，绑定逻辑放视图自己的 bind 函数
   （main.ts bindView 里按视图 import 调用），与 DataTable 分页事件互不干扰。
6. 数据少（<15 行）的视图可暂不接（如 probes/certs），设备规模上来再统一。

## 5. 踩坑记录（全部实战踩过，修复已内置，排障必读）

### 5.1 TDZ 死区：解构变量与函数同名 → minify 后报 Cannot access 'i' before initialization
- **现象**：构建产物运行报 `Uncaught ReferenceError: Cannot access 'i' before initialization`，页面白屏。
- **根因**：`const { pageRows, total } = pageRows(...)` —— 解构目标与函数同名，右侧调用落在 TDZ
  （暂时性死区）；esbuild minify 变量重命名后错误信息变成 `'i'`，极难定位。
- **修复**：函数返回 `{ items, total, pages }`，解构改名 `paged.items`，避免与函数名碰撞。
- **教训**：**解构变量名不要与同作用域函数/变量重名**；minify 产物报 `Cannot access 'x'` 先查 TDZ。

### 5.2 事件重复绑定：data-tb 多处标记 → 点一次上一页跳 0 页
- **现象**：翻到第 2 页点"上一页"跳到第 0 页（负页被钳制显示为 0/1）。
- **根因**：渲染时 twrap/tbar/tagg/tpager **四处都带 `data-tb`**，`bindTableForView` 用
  `querySelectorAll("[data-tb]")` 匹配 4 个元素各绑一遍 → 点一次执行 4 次 `s.page -= 1`。
- **修复**：`data-tb` **只标记最外层 twrap**（唯一锚点），绑定改用 `querySelector`（取第一个）；
  同时 pageRows 加 `page < 1` 钳制兜底。
- **教训**：**绑定锚点属性必须全局唯一**；相对状态变更（page ±1）重复绑定会成倍放大。

### 5.3 TS 泛型索引报错：TS7053 Element implicitly has 'any' type
- **现象**：`r[c.key]`（r: T 泛型）报 TS7053，无索引签名。
- **修复**：`(r as any)[c.key]`（组件内部 5 处）。
- **教训**：泛型组件内动态取字段必须 `as any`；视图层 fmt 里用具体类型不受影响。

### 5.4 筛选值显示：0/1 等原始值不友好
- **现象**：告警"已解决"列筛选下拉显示 `0`/`1`。
- **修复**：ColDef 增加 `filterMap: {原始值: 显示名}`，下拉显示名、过滤用原始值。
- **教训**：**展示友好值与过滤原始值分离**，不要为了显示改数据。
