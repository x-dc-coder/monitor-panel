# monitor-panel 设备接入手册（扩展性指南）

> 日期：2026-08-16 ｜ 配套：《monitor-panel 技术方案 v1.1》《Headscale 设备管理手册》
> 本文记录如何便捷接入新设备（阿里云/树莓派/其他），以及架构预留的扩展位。

## 1. 接入方式总览（按便捷度排序）

| 设备类型 | 接入方式 | 需要改动 | 便捷度 |
|---|---|---|---|
| 任意设备（手机/平板/树莓派） | 仅 tailscale 入网 | 零代码（面板自动发现） | ⭐⭐⭐ |
| 局域网无 tailscale 设备（NAS/打印机） | 子网路由（subnet router） | 入网设备加 --advertise-routes | ⭐⭐⭐ |
| 第二台云服务器（阿里云 cloud-2） | tailscale 入网 + 探测对 | config 加一行 | ⭐⭐⭐ |
| 需要上报详细指标的设备 | agent 上报模式（POST /api/ingest） | 二期（agent + nginx location） | ⭐⭐ |

## 2. 快速接入步骤

### 2.1 任意设备（树莓派/新手机）
```bash
# ① 服务端生成密钥（cloud 上）
sudo headscale preauthkeys create -u 1

# ② 设备上安装并入网
curl -fsSL https://tailscale.com/install.sh | sh
sudo tailscale up --login-server https://headscale.dc-sy.cn --authkey <KEY>

# ③ hosts（若 DNS 异常，见 headscale-tailscale.md 雷区1）
echo "124.221.190.237 headscale.dc-sy.cn" | sudo tee -a /etc/hosts

# ④ 面板自动显示（tailscale status 采集 30s 内）
```
**树莓派提示**：可同时 `--advertise-routes=192.168.0.0/24` 把家里局域网带进尾网。

### 2.2 阿里云云服务器（cloud-2，双公网 IP 兜底）
```yaml
# ① tailscale 入网（同上，成为第二个节点）
# ② 面板 config.probes 加探测对（cloud 主面板 config.py 或 .env MONITOR_PROBES）
{"name":"cloud2-443","kind":"tcp","target":"<cloud2公网IP>","port":443},
{"name":"cloud2-ping","kind":"icmp","target":"<cloud2公网IP>"}

# ③（二期）cloud-2 跑 agent → POST /api/ingest（需 nginx location 暴露 + Bearer token）
# ④ monitor_nodes 表加一行（node_id='cloud-2', role='fallback'）
```

### 2.3 无需入网设备（子网路由）
```bash
# 入网设备（如树莓派）宣告子网
sudo tailscale up --advertise-routes=192.168.0.0/24
# headscale 批准
sudo headscale routes list && sudo headscale routes approve -r <ID>
```

## 3. 架构预留（一期即生效）

| 预留点 | 说明 |
|---|---|
| **node_id 字段** | devices/tunnels/samples/alerts 全带 node_id，加节点零 schema 变更 |
| **探测对配置化** | config.probes 数组，加一行即新探测（含多节点互检） |
| **agent 上报模式** | `POST /api/ingest` 预留（默认 404，二期启用），与自采同构 CollectorResult |
| **DEVICE_MAP** | tailscale HostName ↔ 8899 device_id 对照，config 加键即关联 |
| **数据库固定** | /opt/monitor-panel/data（MONITOR_DB_PATH），release 切换不丢数据 |

## 4. 接入 checklist

- [ ] tailscale 入网成功（headscale nodes list 可见）
- [ ] 面板 devices 页出现该设备（30s 内）
- [ ] ping 轮巡正常（延迟/路径显示）
- [ ] （云服务器）探测对配置 + 公网 IP 可达
- [ ] （可选）DEVICE_MAP 关联 8899 设备

## 5. 注意事项

- 密钥一次性 + 1h 过期（headscale-tailscale.md 雷区2）
- 设备离线时不 ping 不告警（防休眠误报）
- tailscale ping 需 sudoers 白名单（deploy/sudoers.monitor）
- 阿里云接入涉及新云资源与防火墙，需单独决策与审批
