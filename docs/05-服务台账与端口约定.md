# 05 · 服务台账与端口约定（issue #2 方案 C）

> 版本：v1.0 ｜ 日期：2026-08-17
> 关联：issue #2（服务台账）、issue #1（配置统一）、技术方案 §1.3（MonitorNode 抽象）
> 核心思想：**端口范围即隐式注册表** —— 自定义项目/网站统一绑定在约定区间内，
> 面板自动扫描该区间完成服务发现与探活，部署即登记，零人工维护。

## 1. 端口分区约定（全设备统一遵守）

| 区段 | 用途 | 管理方式 |
|---|---|---|
| <1024 | 系统固定端口（22/53/80/443…） | manual 登记（config `SERVICES_MANUAL` / db source=manual），不自动扫描 |
| 1024–9999 | 存量/通用端口（5000 摄像头、7500 frps dashboard、8080 headscale、8898/8899 面板、9090 metrics） | manual 登记 + 自动标注；不自动扫描 |
| **10000–19999** | **自定义项目/网站约定区** | **自动扫描纳管（默认 `MONITOR_SERVICES_PORT_RANGE=[10000,19999]`）** |
| 20000–20099 | frp 远程端口池（frps allowPorts） | 走 tunnels 表（frp 采集器），天然不冲突 |

### 约定区内部分配建议

`10000 + 项目号×10 + 服务序号`，例如：

- 10000–10009：本面板相关（10000 本地预览 / 10001 cloud 面板备用）
- 10010–10019：摄像头/监控类（10010 摄像头 Web）
- 10020–10029：自建 Web 站点
- 10030–10039：数据库/存储类管理端（只绑 tailscale）
- …按项目递增，新项目从下一个 10 段开始

**约束**：任何新服务（Docker 映射、uvicorn、node 等）绑定端口时，自定义服务一律落在
`10000–19999`；固定系统端口不受此约束；frp 隧道远程端口不占本区间。

## 2. 自动发现机制

- **扫描目标**：tailscale 在线设备（devices 表 online=1）+ 本机 127.0.0.1（device_id=local）
- **扫描范围**：`SERVICES_PORT_RANGE` 区间，**分片轮巡**：每轮每设备扫 `SERVICES_SCAN_BATCH`
  （默认 256）个端口，多轮覆盖全量；已登记端口每轮必探（状态保鲜）
- **探测**：TCP 全连接（`asyncio.open_connection`，超时 1.5s，并发 64 硬限）；不做 SYN 半开
- **协议识别**：连接后 `GET / HTTP/1.0`（2s 超时，读 2KB）→ http（status/title/Server 头）；
  否则读 1s banner 判 ssh；其余标记 tcp
- **状态语义**：open → 连续 `SERVICES_MISSING_ROUNDS`（默认 3）轮未开放 → closed（保留行置灰）
- **命名**：人工覆盖名（`SERVICES_ALIASES`，键 `ip:port`）> HTTP `<title>` > `Server` 头 > `设备名:端口`
- **指标**：`latency_ms.<ip:port>` / `reachable.<ip:port>`（group=services，趋势图直接可用）

## 3. 数据模型

services 表（db.py）：node_id / device_id / device_name / tailscale_ip / port / name（人工覆盖）/
auto_name / protocol / url / http_status / latency_ms / status（open|closed|unknown）/
missing_rounds / source（auto|manual）/ enabled / first_seen_ts / last_seen_ts / updated_ts，
UNIQUE(node_id, device_id, port)。

## 4. 配置项（.env）

```bash
MONITOR_SERVICES_PORT_RANGE=[10000,19999]   # 约定区
MONITOR_SERVICES_ALIASES={}                 # {"ip:port": "显示名"}
MONITOR_SERVICES_SCAN_BATCH=256             # 每轮每设备扫描端口数（分片）
MONITOR_SERVICES_CONNECT_TIMEOUT=1.5        # TCP 连接超时（秒）
MONITOR_SERVICES_HTTP_TIMEOUT=2.0           # HTTP 识别超时（秒）
MONITOR_SERVICES_CONCURRENCY=64             # 并发上限
MONITOR_SERVICES_MISSING_ROUNDS=3           # 连续 N 轮未开放 → closed
MONITOR_INTERVAL_SERVICES=60                # 扫描周期（秒）
```

## 5. 边界与注意事项

1. 端口约定是软约束：区间外的服务不会被自动纳管 → 走 manual 登记；
2. 约定区内第三方工具占用 = 可接受噪音，靠别名/认领收敛；
3. 只扫在线设备 + 本机，离线设备跳过（防超时放大）；
4. 扫描仅限 tailscale 内网 + 回环，不触公网；全连接探测无 root/防火墙问题；
5. 手动登记（source=manual）同样参与探活，但**不做发现**（不在区间内不自动建行）。
